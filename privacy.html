Privacy Policy / Política de Privacidad

Última actualización: 21 de agosto de 2026

1. Introducción

Esta Política de Privacidad describe cómo maneja la información la aplicación Tasting Partner (en adelante, "la Aplicación"), desarrollada por jlopezlabs.

La Aplicación es gratuita y no requiere registro ni creación de cuenta. Toda la información que introduces permanece exclusivamente en tu dispositivo.

2. Información que maneja la Aplicación

2.1 Datos que almacenas en tu dispositivo

La Aplicación almacena únicamente la siguiente información de forma local en tu dispositivo:

  • Nombres y descripciones de catas
  • Productos añadidos a las catas (nombre, marca, cantidad)
  • Puntuaciones y notas de cata (valoraciones de 1 a 5 estrellas y texto libre)
  • Preferencia de idioma de la Aplicación
  • Copias de seguridad exportadas por ti: archivos JSON o CSV que se generan únicamente cuando solicitas una exportación

Estos datos se guardan exclusivamente en el almacenamiento local del dispositivo (AsyncStorage) y nunca se envían a ningún servidor, nube o servicio externo.

2.2 Datos que NO recopilamos

La Aplicación no recopila ningún dato personal identificable, incluyendo:

  • Nombre, correo electrónico, teléfono o dirección
  • Datos de ubicación
  • Información del dispositivo o del sistema
  • Datos de uso o análisis (analytics)
  • Cualquier otro dato que pueda identificarte

2.3 Conexiones a servicios externos

La Aplicación puede realizar consultas de solo lectura a bases de datos públicas de productos alimenticios para obtener información como nombre, marca y datos nutricionales. Estas consultas se limitan a:

  • Búsqueda de productos por nombre o palabra clave
  • Consulta de productos por código de barras escaneado con la cámara

Únicamente se envía el término de búsqueda o el código de barras. No se envía ningún dato personal, identificador de usuario ni información de tu dispositivo.

3. Permisos del dispositivo

La Aplicación solicita acceso a:

  • Cámara: utilizada exclusivamente para escanear códigos de barras de productos alimenticios.

No se solicita acceso a la ubicación, contactos, micrófono ni a ningún permiso general de almacenamiento. Los archivos de copia de seguridad se crean y se leen exclusivamente a través de los selectores del sistema (compartir documentos y selector de archivos), eligiendo tú el archivo o la ubicación en cada caso.

4. Almacenamiento y eliminación de datos

Toda la información almacenada por la Aplicación reside exclusivamente en tu dispositivo. Puedes eliminar todos tus datos en cualquier momento:

  • Desinstalando la Aplicación elimina permanentemente todos los datos almacenados.
  • No existe ninguna copia de seguridad en servidores externos, ya que no se envía ningún dato fuera del dispositivo.
  • Además, desde los ajustes puedes exportar todos tus datos a un archivo de copia de seguridad (JSON) o de hoja de cálculo (CSV) para conservarlos o moverlos a otro dispositivo; importar una copia solo reemplaza tus datos tras tu confirmación explícita.

5. Menores de edad

La Aplicación no recopila datos personales de ningún usuario, incluyendo menores de edad.

6. Cambios en esta política

Si se realizan cambios en esta Política de Privacidad, se publicará la versión actualizada en esta misma página con la fecha de la última actualización.

1. Introduction

This Privacy Policy describes how the Tasting Partner application (hereinafter, "the Application"), developed by jlopezlabs, handles information.

The Application is free and requires no registration or account creation. All information you enter stays exclusively on your device.

2. Information Handled by the Application

2.1 Data stored on your device

The Application stores the following information locally on your device only:

  • Tasting names and descriptions
  • Products added to tastings (name, brand, quantity)
  • Tasting scores and notes (1-5 star ratings and free text)
  • Application language preference
  • Backups you export: JSON or CSV files generated only when you request an export

This data is stored exclusively in the device's local storage (AsyncStorage) and is never sent to any server, cloud service, or external system.

2.2 Data we do NOT collect

The Application does not collect any personally identifiable information, including:

  • Name, email, phone number, or address
  • Location data
  • Device or system information
  • Usage or analytics data
  • Any other data that could identify you

2.3 External service connections

The Application may make read-only queries to public food product databases to retrieve information such as product name, brand, and nutritional data. These queries are limited to:

  • Searching for products by name or keyword
  • Looking up products by barcode scanned with the camera

Only the search term or barcode is transmitted. No personal data, user identifiers, or device information is sent.

3. Device Permissions

The Application requests access to:

  • Camera: used exclusively to scan product barcodes.

No access is requested to location, contacts, microphone, or any general storage permission. Backup files are created and read exclusively through the system's dialogs (share sheet and file picker), with you choosing the file or location each time.

4. Data Storage and Deletion

All data stored by the Application resides exclusively on your device. You can delete all your data at any time:

  • Uninstalling the Application permanently deletes all stored data.
  • No backup copy exists on external servers, as no data is sent outside the device.
  • You can also export all your data from the settings to a backup (JSON) or spreadsheet (CSV) file to keep it or move it to another device; importing a backup only replaces your data after your explicit confirmation.

5. Children's Privacy

The Application does not collect personal data from any user, including children.

6. Changes to This Policy

If changes are made to this Privacy Policy, the updated version will be published on this page with the date of the last update.
